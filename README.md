# Power BI Dashboard – Sales & Order Analytics

A data-driven Power BI dashboard designed to analyze and visualize global sales and order performance using an Excel dataset.

The project demonstrates an end-to-end Business Intelligence workflow, covering data preparation, data modeling, DAX calculations, interactive dashboard design, and business insights.

![Dashboard](Screenshots/Dashboard.png)

![Dataset](Screenshots/Dataset.png)

## 📊 Project Overview

The dashboard analyzes business performance across multiple dimensions, including:

- Sales
    
- Profit
    
- Orders
    
- Customers
    
- Product Categories
    
- Regions
    
- Countries
    
- Customer Segments
    
- Shipping Modes
    
- Time-based trends
    

The dataset contains fields such as Order ID, Date, Customer, Product Category, Region, Segment, Shipping Mode, Cost, Sales, Profit, and Quantity.

## 🛠️ Technologies Used

- **Microsoft Power BI**
    
- **Power Query**
    
- **DAX**
    
- **Microsoft Excel**
    
- **Data Modeling**
    
- **Data Visualization**
    

## 🔧 Data Preparation & Modeling

Power Query was used to clean and transform the raw Excel dataset into a structured format suitable for analysis.

Key activities included:

- Data cleaning and transformation
    
- Data type validation
    
- Structuring the dataset for analysis
    
- Building relationships within the data model
    
- Creating an efficient model for filtering and visualization
    
- Ensuring data integrity
    

## 📐 DAX & Key Metrics

Custom DAX measures and calculated columns were created for important business KPIs, including:

- **Total Sales**
    
- **Total Profit**
    
- **Profit Margin**
    
- **Order Volume**
    
- **Average Sales per Order**
    

Time-based calculations were also implemented to support trend and comparative analysis.

## 📊 Dashboard Features

The dashboard provides an interactive analytical experience using:

- KPI Cards
    
- Bar Charts
    
- Line Charts
    
- Interactive Slicers
    
- Drill-down functionality
    
- Dynamic filtering
    

Users can analyze the data by:

- Region
    
- Country
    
- Segment
    
- Category
    
- Sub-Category
    
- Shipping Mode
    

## 📈 Business Insights

The dashboard enables analysis of:

- Top-performing regions
    
- Most profitable product categories
    
- Customer purchasing patterns
    
- Segment performance
    
- Seasonal sales trends
    
- Shipping efficiency
    
- Dynamic KPI performance
    

## 🎯 Project Outcome

This project demonstrates an end-to-end Power BI workflow, from raw data ingestion and transformation to data modeling, DAX-based analysis, visualization, and business storytelling.

The resulting dashboard provides stakeholders with an interactive way to explore sales and order performance and derive data-informed business insights.
